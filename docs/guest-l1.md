# 손님 1차(L1) 브라우즈

구매자 홈·카테고리 입구는 **게스트 1차 15개**(쿠팡식 겹침 멀티 태그)다. AI-Hub 대분류(`table_taxonomy`)는 등록·관리자 힌트로 남긴다.

태그 자동 규칙 SSOT: [guest-l1-tag-rules.md](./guest-l1-tag-rules.md)

## 15개 1차 (이름 고정, 겹침 허용)

1. 생수/음료
2. 커피/원두/차
3. 과자/초콜릿/시리얼
4. 라면/면류
5. 통조림/캔
6. 반찬/간편식/대용식
7. 국/탕/찌개
8. 즉석밥/볶음밥
9. 죽/스프
10. 분식/만두/피자
11. 짜장/카레/돈까스
12. 냉장/냉동/간편요리
13. 가루/조미료/오일
14. 장류/소스
15. 유제품/아이스크림

신선(과일/채소/수산/정육)은 게스트 1차에 두지 않는다. **보관(상온/냉장/냉동)** 은 1차 화면의 필터다. 12번만 냉장·냉동 간편요리 **입구 이름**이다.

## 축 흐름

1. 홈에서 1차를 고른다.
2. **브랜드부터** / **메뉴부터** 토글 — 누르면 바로 바뀐다. 확인 버튼 없음. 1차마다 기본 축은 있어도 순서를 잠그지 않는다.
3. 브랜드·메뉴 목록은 **그 1차 태그가 붙은 카드만**.
4. 고르면 회사+품목 카드. 카드에 용량·판매자, 담기는 몰 장바구니. 판매자는 내부 가게다.

URL: `/`, `/?l1=라면/면류`, `/?l1=…&axis=brand|menu`, `/?l1=…&brand=` / `&menu=`, `/?l1=…&storage=상온|냉장|냉동`, `/?l1=…&all=1`

## 저장

`catalog_products.l1_tags[]` (15개 중 0~N). 제목·브랜드·기존 중·소분류·보관으로 자동 태깅. high만 자동 저장, mid/low는 MD 승격 칩에서 고친다.

구현: `apps/api/app/services/guest_l1.py`
