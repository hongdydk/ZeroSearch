# 손님 1차(L1) 브라우즈

구매자 홈·카테고리 입구는 **게스트 1차 15개**(쿠팡식 겹침 멀티 태그)다. AI-Hub 대분류(`table_taxonomy`)는 등록·관리자 힌트로 남긴다.

태그 자동 규칙 SSOT: [guest-l1-tag-rules.md](./guest-l1-tag-rules.md) · [guest-l2-tag-rules.md](./guest-l2-tag-rules.md)

## 15개 1차 (이름 고정, 겹침 허용)

1. 생수/음료
2. 커피/원두/차
3. 과자/초콜릿/시리얼
4. 라면/면류
5. 통조림/캔
6. 반찬/간편식/대용식
7. 국/탕/찌개
8. 즉석밥/볶음밥
9. 죽/스프
10. 분식/만두/피자
11. 짜장/카레/돈까스
12. 냉장/냉동/간편요리
13. 가루/조미료/오일
14. 장류/소스
15. 유제품/아이스크림

신선(과일/채소/수산/정육)은 게스트 1차에 두지 않는다. **보관(상온/냉장/냉동)** 은 1차 화면의 필터가 아니라, L2를 고른 뒤 축 화면의 필터다. 12번만 냉장·냉동 간편요리 **입구 이름**이다.

## 2차(L2) — 손님 언어, 1차마다 3–7개

L2는 **장보기 손님 말**이다. 등록·관리자의 대·중·소 트리를 손님 화면에 그대로 쓰지 않는다. 한 품목이 여러 L2에 걸려도 된다. L1으로 들어온 뒤에는 L2를 고르기 **전에** 브랜드·메뉴·오퍼 벽을 풀지 않는다.

1. 생수/음료: 생수, 탄산·이온·스포츠, 주스·과채, 전통음료, 병·캔 커피·차, 기타음료
2. 커피/원두/차: 원두·캡슐, 커피믹스, 티백·잎차, RTD 커피·차, 코코아·기타
3. 과자/초콜릿/시리얼: 스낵·과자, 초콜릿·캔디, 시리얼·바, 안주·육포
4. 라면/면류: 봉지라면, 컵·용기면, 국수·당면·파스타, 냉면·기타면
5. 통조림/캔: 참치·수산캔, 햄·고기캔, 농산·과일캔, 기타캔
6. 반찬/간편식/대용식: 즉석반찬, 간편식·도시락, 대용식·선식, 기타
7. 국/탕/찌개: 국, 탕, 찌개, 분말·즉석국
8. 즉석밥/볶음밥: 흰밥·잡곡밥, 볶음밥·컵밥, 주먹밥·기타
9. 죽/스프: 죽, 스프, 미음·기타
10. 분식/만두/피자: 만두·교자, 떡볶이·어묵, 피자·핫도그, 기타분식
11. 짜장/카레/돈까스: 짜장, 카레, 돈까스·커틀릿, 너겟·강정
12. 냉장/냉동/간편요리: 냉장HMR, 냉동HMR, 냉동만두·분식, 기타냉동
13. 가루/조미료/오일: 가루·분말, 조미료, 식용유·참기름, 기타
14. 장류/소스: 고추장·된장·쌈장, 간장, 소스·드레싱, 식초·맛술
15. 유제품/아이스크림: 우유, 요거트·치즈·버터, 아이스크림·빙과

코드 SSOT: `apps/api/app/services/guest_l2.py` · `apps/flutter/lib/core/catalog/guest_l1.dart`

## 축 흐름

1. 홈에서 1차를 고른다.
2. **그 1차의 L2**를 고른다. 확인 버튼 없음. L2 전에는 브랜드·메뉴·판매자 오퍼 목록을 열지 않는다.
3. **브랜드부터** / **메뉴부터** / **판매자 오퍼** 토글 — 누르면 바로 바뀐다. 확인 버튼 없음. 1차마다 기본 축은 브랜드 또는 메뉴여도 순서를 잠그지 않는다.
4. 브랜드·메뉴 목록은 **그 1차+L2 태그가 붙은 카드만**. 고르면 회사+품목 카드(identity collapse). 같은 회사의 근사 중복 제목(반복 접미·용량 단위 표기 `1L`/`1리터`/`1000ml`)은 엔진이 한 장으로 접는다. 제조사가 다르거나 핵심 명사·맛이 다른 품목은 접지 않는다. L1 범위·`axis=seller`(가게 리스팅마다 한 장)는 그대로다.
5. **판매자 오퍼**는 쿠팡/네이버식: 공개 오퍼(가게 리스팅)마다 카드 한 장. 대·중·소 분류가 아니다. 가게·가격을 카드에 보여 준다.
6. 검색(`/?q=`) 뒤에도 같은 세 축으로 좁힌다. 검색은 L1 입구가 아니므로 L2를 강제하지 않는다. 1차로 들어왔으면 세 축 모두 그 L1+L2 범위 안.
7. 목록·패싯·오퍼 API는 `l1_tags`·`l2_tags` 교집합이다. 1차 밖에서 브랜드/메뉴 문자열만 맞추지 않는다. 알 수 없는 `l1Tag`·해당 1차에 없는 `l2Tag`는 빈 결과. L2 미태그는 그 L2 필터에서 빠진다(fail-closed).

URL: `/`, `/?l1=라면/면류`, `/?l1=…&l2=봉지라면`, `/?l1=…&l2=…&axis=brand|menu|seller`, `/?l1=…&l2=…&brand=` / `&menu=`, `/?l1=…&l2=…&storage=상온|냉장|냉동`, `/?l1=…&l2=…&all=1`, `/?q=…&axis=brand|menu|seller`

## 저장

`catalog_products.l1_tags[]` (15개 중 0~N). `catalog_products.l2_tags[]` (해당 1차 L2 이름, 0~N, 겹침 허용). L1은 제목·브랜드·중·소분류·보관, L2 high는 상품명(분류만 맞으면 mid). high만 자동 저장, mid/low·애매하면 MD 게이트 또는 미태그. 미태그는 그 L2 목록에 안 나온다.

구현: `apps/api/app/services/guest_l1.py`, `apps/api/app/services/guest_l2.py`. L2 high는 상품명, 중·소분류만 맞으면 mid(미태그).
