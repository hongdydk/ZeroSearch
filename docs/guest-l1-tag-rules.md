# ZeroSearch 1차 태그 자동 규칙 초안

- 방식: **멀티 태그** (한 상품이 여러 1차에 걸릴 수 있음)
- 입력: 상품명, 브랜드, (있으면) 기존 중·소분류, 보관(상온/냉장/냉동)
- 출력: 1차 태그 0~N개 + 신뢰도(high/mid/low)
- high만 자동 확정 후보, mid/low는 MD 승인 게이트에서 확인
- 확정 1차 15개 (쿠팡식, 신선 제외)

## 1차 목록

1. 생수/음료
2. 커피/원두/차
3. 과자/초콜릿/시리얼
4. 라면/면류
5. 통조림/캔
6. 반찬/간편식/대용식
7. 국/탕/찌개
8. 즉석밥/볶음밥
9. 죽/스프
10. 분식/만두/피자
11. 짜장/카레/돈까스
12. 냉장/냉동/간편요리
13. 가루/조미료/오일
14. 장류/소스
15. 유제품/아이스크림

## 적용 순서 (엔진)

1. **보관 태그**  
   - 보관 ∈ {냉장, 냉동} 이고, 한 끼/조리 키워드(만두, 돈까스, 피자, 찌개, 볶음밥, 치킨, 핫도그, 튀김, 밀키트 등) → `냉장/냉동/간편요리` 추가 (high)
2. **strong 키워드 스캔** → 해당 1차 high
3. **겹침 규칙**
   - 만두|피자|핫도그|떡볶이|어묵 → `분식/만두/피자` + (냉장/냉동이면) `냉장/냉동/간편요리`
   - 돈까스|카레|짜장소스|너겟 → `짜장/카레/돈까스` + (냉장/냉동이면) `냉장/냉동/간편요리`
   - 찌개|국|탕 (즉석/레토르트/냉동) → `국/탕/찌개` + `반찬/간편식/대용식` (+ 냉동이면 12번)
4. **폴백**  
   - 한 끼·즉석·레토르트인데 위 태그 0개 → `반찬/간편식/대용식` (mid)
5. **충돌 완화**
   - 건면 파스타 → `라면/면류` (고), `분식/만두/피자` 제외
   - 파스타소스 → `장류/소스` (고), 면류 제외
   - 상온 레토르트 찌개 → 12번 제외

## 신뢰도

| 등급 | 조건 | 처리 |
|---|---|---|
| high | strong 키워드 또는 보관+조리 키워드 명확 | 초안에 자동 포함, MD는 눈검만 |
| mid | weak 키워드만 / 폴백 | 초안 포함, MD 확인 필수 |
| low | 모델 추정만 | 태그 제안만, 기본 미체크 |

## 요리명 예외 (장류/소스 오탐 방지)

레토르트·즉석 **요리** 이름에 장·소스 원재료가 들어가도, 상품이 장류 자체가 아닌 경우가 많다.
예: `된장찌개`를 `된장`으로 장류/소스에 넣지 않음.

**규칙:** 상품명에 아래 **요리형 접미/키워드**가 있으면, 장류 원재료 키워드로는 `장류/소스`를 **붙이지 않는다.**

요리형: `찌개`, `국`, `탕`, `전골`, `볶음`, `조림`, `무침`, `찜`, `구이`, `밥`, `면`, `라면`, `죽`, `스프`, `수프`, `소스맛`(과자 플레이버), `맛`(스낵 플레이버 — 별도 과자 규칙과 함께)

이 예외가 켜진 뒤에도 `장류/소스`가 되려면 아래처럼 **장 자체**여야 한다.
- high: `고추장`, `된장`, `쌈장`, `간장` 등 + 요리형 접미 **없음**
- 또는 `○○소스`이되 요리 완제품이 아님 (`파스타소스`, `돈까스소스`, `돈까스소스` 등 조미 소스)

**예시**
| 상품명 | 결과 |
|---|---|
| 오뚜기 된장찌개 레토르트 | `국/탕/찌개` (+필요 시 `반찬/간편식/대용식`) — `장류/소스` 제외 |
| 청정원 된장 500g | `장류/소스` |
| 오리온 스윙칩 볶음고추장맛 | `과자/초콜릿/시리얼` — `장류/소스` 제외 |
| 오뚜기 카레 약간매운맛 | `짜장/카레/돈까스` |

## MD 게이트

- 판매자/시드 등록 → 규칙으로 태그 초안 생성
- 승인 화면에서 15개 칩 토글 (겹침 허용)
- 승인 시 상품(카드)에 `l1_tags[]` 저장
- 손님 브라우즈는 `l1_tags` 포함 여부로 필터
