# ZeroSearch 2차(L2) 태그 자동 규칙

- 방식: **멀티 태그** (한 상품이 여러 2차에 걸릴 수 있음). 1차 태그가 붙은 칸 안에서만 2차를 고른다.
- 입력: 상품명, 브랜드, (있으면) 기존 중·소분류, 보관, **확정/추론 1차 태그**
- 출력: 2차 태그 0~N개 + 신뢰도(high/mid/low)
- high만 자동 확정. mid/low·여러 칸이 비슷하게만 맞으면 **미태그**. 그 L2 필터에서는 안 나온다(fail-closed).
- 손님 L2 이름 SSOT: [guest-l1.md](./guest-l1.md). 등록 대·중·소 트리와 같지 않다.
- 1차 규칙과 충돌하지 않게: 1차가 안 붙으면 2차도 안 붙는다.

## 적용 순서 (엔진)

1. 1차 태그가 있는 칸만 본다.
2. 그 칸의 **strong 키워드**만 high. 약한 말은 mid — 자동 저장하지 않음.
3. 같은 1차 안에서 여러 L2 high가 나오면 **겹침 허용**.
4. 컵/봉지, 원두/RTD, 국/분말국처럼 갈라지는 신호는 더 구체적인 쪽만 high. 갈라지지 않으면 미태그.
5. `기타`·`기타음료` 같은 나머지 칸은 **그 칸 전용 키워드**가 있을 때만. 애매한 상품을 나머지로 쓸어 담지 않음.

## 규칙 표 (키워드 → L2)

매칭은 상품명·분류 부분문자열. 아래는 high. 목록에 없는 말은 자동 저장하지 않는다.

### 생수/음료

- 생수: 생수, 먹는샘물, 삼다수, 백산수, 평창수
- 탄산·이온·스포츠: 탄산수, 탄산음료, 콜라, 사이다, 이온음료, 스포츠음료, 포카리, 게토레이
- 주스·과채: 주스, 과채음료, 착즙, juice
- 전통음료: 식혜, 수정과, 숭늉, 전통음료, 보리차, 옥수수차
- 병·캔 커피·차: 커피음료, 캔커피, 병커피, 아이스티, 티음료, 페트커피
- 기타음료: 두유, 알로에음료, 콤부차, 에이드, 쿨피스

### 커피/원두/차

- 원두·캡슐: 원두, 캡슐커피, 홀빈, 분쇄원두
- 커피믹스: 커피믹스, 믹스커피, 모카골드
- 티백·잎차: 티백, 잎차, 녹차, 홍차, 허브차, 둥굴레, 도라지차, 유자차
- RTD 커피·차: 커피음료, 캔커피, 콜드브루음료, 아이스티, 티음료
- 코코아·기타: 코코아, 핫초코

원두 vs RTD: `원두`·`캡슐`이 있으면 원두·캡슐. `음료`·`캔`·`페트`·`병`이 있으면 RTD. `콜드브루`만 있으면 미태그.

### 과자/초콜릿/시리얼

- 스낵·과자: 과자, 스낵, 쿠키, 파이, 비스킷, 팝콘, 포카칩, 스윙칩, 새우깡, 감자깡
- 초콜릿·캔디: 초콜릿, 초콜렛, 젤리, 캔디, 껌
- 시리얼·바: 시리얼, 씨리얼, 그래놀라, 시리얼바, 씨리얼바
- 안주·육포: 육포, 어포, 쥐포, 안주꼬치, 안주

쿠키·파이의 초코 플레이버는 스낵·과자. 초코 자체가 품목일 때만 초콜릿·캔디.

### 라면/면류

- 봉지라면: 봉지라면, 봉지면, 국물봉지라면, 비빔봉지라면, 신라면, 진라면, 너구리, 안성탕면, 짜파게티
- 컵·용기면: 컵라면, 용기면, 사발면, 큰사발, 컵누들, 국물용기라면, 비빔용기라면
- 국수·당면·파스타: 국수, 소면, 중면, 당면, 칼국수, 쌀국수, 파스타, 스파게티, 우동
- 냉면·기타면: 냉면, 쫄면, 메밀면

컵/사발/용기 신호가 있으면 컵·용기면만. `라면`만 있고 봉지·컵이 안 보이면 미태그.

### 통조림/캔

- 참치·수산캔: 캔참치, 참치캔, 골뱅이캔, 꽁치캔, 연어캔, 고등어캔
- 햄·고기캔: 스팸, 햄캔, 리챔, 런천미트
- 농산·과일캔: 옥수수캔, 과일통조림, 황도캔, 과일캔
- 기타캔: 기타캔, 죽캔

`통조림`만 있으면 미태그(어느 캔인지 모름).

### 반찬/간편식/대용식

- 즉석반찬: 즉석반찬, 반찬, 장조림, 잡채, 나물
- 간편식·도시락: 도시락, 간편식, 레토르트
- 대용식·선식: 대용식, 선식, 곤약밥
- 기타: (전용 키워드 없음 — 자동 안 함)

### 국/탕/찌개

- 국: 미역국, 북어국, 콩나물국, 황태국, 육개장
- 탕: 설렁탕, 곰탕, 삼계탕, 갈비탕, 도가니탕
- 찌개: 찌개, 된장찌개, 김치찌개, 순두부찌개, 부대찌개
- 분말·즉석국: 분말국, 즉석국, 컵국

`분말`·`가루`가 있으면 분말·즉석국. `국`만 있으면 미태그(`국수` 제외는 1차 규칙과 같음).

### 즉석밥/볶음밥

- 흰밥·잡곡밥: 햇반, 즉석밥, 백미밥, 잡곡밥, 현미밥
- 볶음밥·컵밥: 볶음밥, 컵밥, 덮밥, 비빔밥
- 주먹밥·기타: 주먹밥, 삼각김밥

### 죽/스프

- 죽: 죽, 즉석죽, porridge
- 스프: 스프, 수프, soup, 포터지
- 미음·기타: 미음

### 분식/만두/피자

- 만두·교자: 만두, 교자, 딤섬
- 떡볶이·어묵: 떡볶이, 어묵, 오뎅, 떡국떡
- 피자·핫도그: 피자, 핫도그
- 기타분식: 쫄면, 순대, 분식

### 짜장/카레/돈까스

- 짜장: 짜장, 짜장소스
- 카레: 카레, 카레소스
- 돈까스·커틀릿: 돈까스, 돈가스, 포크커틀릿, 함박스테이크, 커틀릿
- 너겟·강정: 너겟, 강정

### 냉장/냉동/간편요리

- 냉장HMR: 보관=냉장 + 한 끼/조리(만두·찌개·볶음밥·밀키트 등)이되 아래 냉동만두·분식이 아님
- 냉동HMR: 보관=냉동 + 한 끼/조리, 만두·분식 키워드 없음
- 냉동만두·분식: 보관=냉동 + (만두|교자|떡볶이|어묵|피자|핫도그|딤섬)
- 기타냉동: (전용 키워드 없음 — 자동 안 함)

상온 레토르트는 이 1차 자체가 없다.

### 가루/조미료/오일

- 가루·분말: 밀가루, 부침가루, 튀김가루, 설탕, 전분
- 조미료: 다시다, 미원, 후추, 조미료, 소금
- 식용유·참기름: 식용유, 참기름, 들기름
- 기타: 올리고당, 물엿, 조청

### 장류/소스

- 고추장·된장·쌈장: 고추장, 된장, 쌈장, 초고추장, 볶음고추장
- 간장: 간장
- 소스·드레싱: 케첩, 마요네즈, 드레싱, 칠리소스, 돈까스소스, 파스타소스
- 식초·맛술: 식초, 맛술

요리 이름(된장찌개 등)은 1차와 같이 장류 원재료만으로 붙이지 않는다.

### 유제품/아이스크림

- 우유: 우유, 멸균우유
- 요거트·치즈·버터: 요거트, 요구르트, 치즈, 버터, 생크림, 연유
- 아이스크림·빙과: 아이스크림, 빙과, 아이스바

초코우유는 우유. 시리얼바의 `바`는 여기 쓰지 않음.

## 예시

| 상품명 예 | L1 | L2 |
|---|---|---|
| 제주 삼다수 2L | 생수/음료 | 생수 |
| 농심 신라면 5입 | 라면/면류 | 봉지라면 |
| 육개장사발면 | 라면/면류 | 컵·용기면 |
| 비비고 왕교자 (냉동) | 분식/만두/피자, 냉장/냉동/간편요리 | 만두·교자, 냉동만두·분식 |
| 오뚜기 된장찌개 레토르트 | 국/탕/찌개, 반찬/간편식/대용식 | 찌개, 간편식·도시락 |
| 서울우유 1L | 유제품/아이스크림 | 우유 |
| 청정원 고추장 | 장류/소스 | 고추장·된장·쌈장 |
| 허쉬 초콜릿칩 쿠키 | 과자/초콜릿/시리얼 | 스낵·과자 |
| 커피필터 | (없음) | (없음) |
