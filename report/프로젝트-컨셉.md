# 프로젝트 컨셉 — 제로 서치 (Zero Search)

**읽는 사람:** 기획·UI·구현·Agent  
**성격:** 제품 방향 SSOT (기능 명세는 `docs/phaseN-spec.md`)

---

## 한 줄

**제로 서치 (Zero Search)** — 검색·목록 **중복을 줄이는** 공식·입점 마켓플레이스.

「생수」처럼 **카테고리·검색어**로 찾으면, 결과는 **백산수·평창수**처럼 **브랜드(제품명)별 카드**다. 같은 브랜드의 500ml·2L·판매자 N곳은 카드로 늘리지 않고, 카드에는 **최저가**만 보인다. 용량·가격·판매자 차이는 상세 **한 줄 비교**에서 고른다.

쿠팡·네이버를 그대로 복제하거나 물류·광고 규모로 겨루는 프로젝트가 아니다.

---

## 제로 서치가 겨냥하는 것

| 문제 | 방향 |
|------|------|
| 같은 브랜드가 용량·판매자마다 카드 N장 | **브랜드(제품명)당 대표 1장** |
| 검색어는 카테고리(생수) | 결과는 **백산수·평창수** 등 브랜드별 |
| 목록에서 가격 비교 | 카드에 연결 오퍼 **최저가** 노출 |
| 용량·판매자·가격 차이 | 상세에서 **오퍼** 한 줄 비교, 나머지는 더보기 |
| 공식·입점 혼재 | 한 목록에 두되, 가게마다 카드를 늘리지 않음 |
| 배송 주체 | 자사배송 / 판매자배송, 줄 단위 상태 (버튼·폴링, 택배 API 없음) |

## 가져오는 골자

| 가져오는 것 | 참고 |
|-------------|------|
| 검색·목록 | 네이버·쿠팡 — 찾고 담기 |
| 공식 + 입점 | 브랜드/스마트스토어, 직매입/입점 |
| 가게별 장바구니 묶음 | 아이디어스 — 담을 때 누가 파는지 보이게 |
| **하지 않음** | 네이버식 숍 N개 나열을 목록·상세 기본값으로 |

## 용어 (phase 스펙·구현)

| 용어 | 뜻 |
|------|-----|
| **검색어·카테고리** | 사용자가 입력하는 넓은 키워드. 예: 「생수」 |
| **대표 상품** | 브랜드·제품명 단위의 목록·검색 카드 1장. 예: 「백산수」「평창수」 — **생수 전체를 1장으로 묶지 않음** |
| **오퍼** | 대표 상품 + 가게 + 용량·규격 + 가격 + 재고. 실제로 담고 결제하는 단위 |
| **최저가** | 해당 대표 상품에 속한 공개 오퍼 중 최소 가격. **목록 카드에 표시** |
| **주문 줄** | 한 결제 안에서 오퍼·가게별로 나뉜 줄 |

### 예시 (생수)

```
검색: 「생수」
  → 목록: 백산수 8,900원~ | 평창수 9,200원~ | …  (브랜드별 1장, 최저가)

상세: 백산수
  → 오퍼: 500ml×20 공식 12,000 | 2L×6 청정마트 9,800 | …
```

## Agent·구현 기준

1. 목록·검색 카드는 **브랜드(제품명)당 1장**. 오퍼(용량·판매자) 수만큼 늘리지 않는다.
2. 목록 카드 가격은 해당 대표 상품 오퍼 **최저가**.
3. 상세 기본 UI는 **오퍼 한 줄 비교**. 숍 전체 나열은 더보기.
4. Phase 스펙 = 만들 계약. 이 문서 = **왜·무엇을 줄이는지**.
5. 새 기능 제안 시: **같은 브랜드 카드 중복을 줄이는지** 먼저 본다.
