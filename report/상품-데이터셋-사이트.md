# 시연용 상품 등록 — 데이터셋·샘플을 구할 수 있는 사이트

시연 때 **공식 스토어·입점 가게에 올라갈 상품**이 필요하다. 판매자가 등록하는 항목은 아래와 같다. 이 문서는 그 항목을 채울 **데이터·이미지를 받을 수 있는 사이트만** 정리한다. (쿠팡·네이버 상품 페이지를 긁어 오는 방식은 쓰지 않는다.)

작성일: 2026-09-01

---

## 1. 우리가 채워야 하는 항목

판매자 상품 등록에 쓰는 값이다.

| 항목 | 필수 | 데이터셋에서 가져올 것 |
|------|------|------------------------|
| 상품명 (`title`) | 필수 | 이름 |
| 설명 (`description`) | 선택 | 한두 문장 소개 |
| 가격 (`price_credits`) | 필수 | 원가·달러가 → 크레딧 정수로 환산 (예: 1,000원 ≈ 1 크레딧, 또는 달러×10) |
| 재고 (`stock`) | 필수 | 없으면 10~100 사이로 직접 넣어도 됨 |
| 카테고리 (`category`) | 필수 | 영문 소문자 한 단어가 다루기 쉽다. 지금 시드는 `electronics` / `fashion` / `accessories` |
| 이미지 주소 (`image_url`) | 선택 | 공개 이미지 URL. 시연은 사진이 있으면 목록이 덜 비어 보인다 |
| 판매자 | 필수 | 데이터셋에 없음. 공식 스토어·입점 가게는 우리가 만든다 |

시연 규모: 공식 스토어 8~15개 + 입점 가게마다 3~8개면 목록·장바구니·판매자별 주문을 보여 주기에 충분하다.

---

## 2. 한 곳에서 이름·설명·가격·카테고리·사진이 나오는 곳 (가장 쓰기 좋음)

가입 없이 GET만 하면 JSON이 온다. **시연 상품의 1순위**다.

### 2.1 DummyJSON Products — 추천

- 사이트: [https://dummyjson.com/docs/products](https://dummyjson.com/docs/products)
- 목록: `https://dummyjson.com/products` (기본 30개, `?limit=0`이면 전체)
- 카테고리: `https://dummyjson.com/products/categories`

나오는 값: `title`, `description`, `price`, `stock`, `category`, `thumbnail` / `images`.  
우리가 쓰는 항목과 거의 1:1이다. 재고까지 있어서 따로 지어 넣을 일이 적다.

### 2.2 Fake Store API

- 사이트: [https://fakestoreapi.com](https://fakestoreapi.com)
- 목록: `https://fakestoreapi.com/products` (20개)

나오는 값: `title`, `price`, `description`, `category`, `image`.  
재고는 없다. 직접 숫자를 넣으면 된다. 양이 적어서 빠르게 시드 만들 때 좋다.

### 2.3 Platzi Fake Store API

- 문서: [https://fakeapi.platzi.com](https://fakeapi.platzi.com)
- 목록: `https://api.escuelajs.co/api/v1/products`
- 카테고리: `https://api.escuelajs.co/api/v1/categories`

나오는 값: `title`, `price`, `description`, `category`, `images`.  
상품 수가 DummyJSON·Fake Store보다 많다. 입점 가게를 여러 개 채울 때 쓰기 좋다.

---

## 3. 한글 상품명·가격이 필요할 때

위 세 곳은 영어 상품이 기본이다. 시연 화면을 한글로 채우려면 아래를 쓴다.

### 3.1 공공데이터포털 (data.go.kr)

- 사이트: [https://www.data.go.kr](https://www.data.go.kr)
- 회원 가입 후 활용 신청·인증키가 필요한 API가 많다. 파일 다운로드만 되는 데이터도 있다.

시연 상품에 가까운 것:

| 데이터 | 주소 | 쓸 수 있는 것 |
|--------|------|----------------|
| 공영홈쇼핑 편성정보 | [data.go.kr/data/15064538](https://www.data.go.kr/data/15064538/openapi.do) | 상품명, 대표 이미지, 정상가·판매가. 한글 이름+사진+가격이 한 세트 |
| 조달청 디지털서비스몰 계약상품 | [data.go.kr/data/15131726](https://www.data.go.kr/data/15131726/fileData.do) | 상품명, 대분류·중분류, 단가. 파일로 내려받을 수 있음. 이미지는 약함 |

포털 검색어: `상품명`, `판매가`, `편성정보`, `계약상품`.  
매출 비중·검색어 순위만 있는 데이터는 상품 카드에 쓸 이름·사진이 없으니 건너뛴다.

### 3.2 Open Food Facts (식품만)

- 데이터: [https://world.openfoodfacts.org/data](https://world.openfoodfacts.org/data)
- 한국 식품: [https://kr.openfoodfacts.org](https://kr.openfoodfacts.org)

상품명, 설명, 카테고리, 사진이 있다. 가격은 없는 경우가 많다. **공식 스토어를 식품·생필품 톤으로 잡을 때**만 쓰면 된다.

---

## 4. 이미지만 따로 구할 때

이름·가격은 표나 JSON에서 가져오고, 사진만 비어 있을 때.

| 사이트 | 주소 | 메모 |
|--------|------|------|
| Unsplash | [https://unsplash.com](https://unsplash.com) | 무료 사진. 라이선스에 따라 출처 표기가 필요할 수 있음. API: [unsplash.com/developers](https://unsplash.com/developers) |
| Pexels | [https://www.pexels.com](https://www.pexels.com) | 무료 사진·영상. API: [pexels.com/api](https://www.pexels.com/api/) |
| Lorem Picsum | [https://picsum.photos](https://picsum.photos) | 자리 채우기용 랜덤 사진. 상품과 안 맞아도 “이미지가 있는 목록”만 보여줄 때 |

DummyJSON·Fake Store·Platzi는 **이미지 URL이 이미 JSON에 들어 있으므로**, 한글이 필요 없으면 사진 사이트를 따로 안 써도 된다.

---

## 5. 파일(CSV)로 많이 받고 싶을 때 — Kaggle

- 사이트: [https://www.kaggle.com/datasets](https://www.kaggle.com/datasets)
- 검색어: `ecommerce products`, `product catalog`, `amazon products`

자주 인용되는 예:

- **Brazilian E-Commerce Public Dataset by Olist** — 상품·판매자가 나뉘어 있어 공식/입점 시연 구조와 닮았다. 상품명·사진은 약한 편이고, 카테고리·판매자 ID는 쓸 만하다.  
  [kaggle.com/datasets/olistbr/brazilian-ecommerce](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

Kaggle 데이터는 **데이터셋마다 라이선스가 다르다.** 시연·과제용인지, 이미지·상품명을 화면에 그대로 넣어도 되는지 페이지의 License를 본다. 아마존 스크랩 데이터는 상품명·사진 저작권 때문에 화면 시연용으로 부적절할 수 있다.

## 6. 이 작품에 맞춰 고르는 법

| 목적 | 사이트 |
|------|--------|
| 빨리 시드 채우기 (영문·사진·재고까지) | DummyJSON |
| 상품 20개만 빠르게 | Fake Store API |
| 입점 가게를 여러 개, 상품을 많이 | Platzi Fake Store |
| 한글 상품명 + 가격 + 사진 | 공공데이터포털 공영홈쇼핑 편성정보 |
| 한글 상품명 + 분류 + 가격 (사진 약함) | 조달청 디지털서비스몰 계약상품 |
| 사진만 비었을 때 | Unsplash / Pexels |

매핑 예 (DummyJSON → 우리 항목):

| DummyJSON | 우리 등록 항목 |
|-----------|----------------|
| `title` | 상품명 |
| `description` | 설명 |
| `price` | 가격(크레딧). 소수점은 반올림 |
| `stock` | 재고 |
| `category` | 카테고리. 필요하면 `electronics` / `fashion` / `accessories`로 묶기 |
| `thumbnail` | 이미지 주소 |

판매자(공식/입점)는 데이터셋에 없으니, 상품을 가져온 뒤 **공식 스토어 몇 개 · 입점 가게 몇 개**에 나눠 담으면 된다.

---

## 7. 쓰지 말 것

- 쿠팡·네이버쇼핑·스마트스토어 상품 상세를 자동으로 수집하는 것
- 라이선스가 불명확한 “아마존 상품 스크랩 CSV”를 화면에 그대로 올리는 것
- 로고·브랜드 컷을 상품 사진인 것처럼 쓰는 것

시연은 **샘플 API·공공데이터·무료 스톡 사진**이면 충분하다.
